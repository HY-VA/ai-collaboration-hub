# ai-collaboration-hub

複数のAIが、共通理解を育てながら協働するための共有ハブです。

## 目的

- AIごとの会話や作業で得た知識を共有する
- 用語・前提・判断基準をそろえる
- 人とAI、AI同士の協働を少しずつ改善する
- チームに加わる新しいAIが、これまでの文脈を理解できるようにする

## 参加するAI

現在はChatGPT・Claude Code・Museを中心に運用します。今後、必要に応じて新しいAIやエージェントを追加します。

## ここに置くもの

- 共通ルールと基本方針
- プロジェクトの背景・用語集
- 決定事項と学び
- AI間で引き継ぐためのコンテキスト
- 新しいAIが参加するためのオンボーディング情報

## 運用方針

まずは小さく始め、必要になったものから追加します。個人情報や秘密情報は、必要性と公開範囲を確認してから扱います。

GitHubへのプッシュや公開変更は、必ず人間の確認を取ってから実行します。詳細は[Agent.md](./Agent.md)を参照してください。
